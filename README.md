#  Stepping into Data Science: Python Core Libraries

Taking my first steps toward data science by mastering the actual core: **Data Analysis**. 

Instead of just watching tutorials, I built this repository as my digital workspace to write code, solve practical exercises, and get my hands dirty with Python's most essential data libraries. Everything here is focused on building a rock-solid foundation from scratch.

---

## The Toolkit I am Practicing

Here are the core libraries I am working with and exactly how I use them:

*   **NumPy:** For handling multi-dimensional arrays and learning the math behind data processing.
*   **Pandas:** My main tool for data manipulation—learning how to clean messy datasets, filter information, and organize rows and columns.
*   **Matplotlib:** For building the initial, foundational plots and learning how charts are structured.
*   **Seaborn:** For turning raw numbers into clean, beautiful, and easy-to-read statistical visualizations.
